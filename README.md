# Formula 1 Cost Cap Impact Analysis

This repository contains the final team project analysis examining the competitive and financial impact of the Formula 1 budget regulations across team performances.

## Deliverables
- **Analysis Notebook**: [`B05-F1-Cost-Cap.ipynb`](B05-F1-Cost-Cap.ipynb)
- **Interactive Environment**: [![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/jennih0209/F1-Cost-Cap-Analysis/blob/main/B05-F1-Cost-Cap.ipynb)

## Overview
- Evaluates field competitiveness and performance parity before and after the introduction of the financial cost cap regulations.
- Utilizes Python, pandas, and data visualization libraries to model team point distributions and season trends.
